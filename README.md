## 3) المعاينة محليًا

افتح `index.html` مباشرة في المتصفح. لا يحتاج أي خادم.
لخادم محلي: `python -m http.server 8080` ثم افتح `http://localhost:8080/`.

---

## 4) النشر (استضافة مجانية دائمة)

- **Netlify Drop:** افتح `https://app.netlify.com/drop` واسحب المجلد كاملًا. (يلاحظ أنه لتفعيل الرابط يجب إنشاء حساب مجاني.)
- **GitHub Pages:** مستودع باسم `milk-cake-bakery` → ارفع الملفات → `Settings → Pages → Deploy from a branch → main / (root)`.
- **Cloudflare Pages:** `Workers & Pages → Create → Pages → Upload assets`.

الدومين الحالي في `sitemap.xml` مؤقت: `https://monstorjohan-png.github.io/milk-cake-bakery/` — يُستبدل عند ربط الدومين النهائي.
